# モーションプレイヤーコンポーネント

キャプチャーしたモーションデータを再生・制御するコンポーネント群。

## 機能
- モーションデータの再生
- 再生速度の制御
- ループ再生
- 一時停止/再開

## 使用方法
```tsx
import { MotionPlayer } from './MotionPlayer';

// 基本的な使用方法
<MotionPlayer
  motionData={capturedData}
  onPlay={() => {
    // 再生開始時の処理
  }}
  onPause={() => {
    // 一時停止時の処理
  }}
/>
```

## 注意点
- メモリ使用量に注意
- 大量のモーションデータの処理
- 再生のタイミング制御
