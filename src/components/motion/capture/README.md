# モーションキャプチャーコンポーネント

MediaPipeを使用したモーションキャプチャー機能を提供するコンポーネント群。

## 機能
- 手のトラッキング
- ポーズトラッキング
- 顔のトラッキング
- リアルタイムデータ取得

## 使用方法
```tsx
import { MotionCapture } from './MotionCapture';

// 基本的な使用方法
<MotionCapture
  onDataReceived={(data) => {
    // トラッキングデータの処理
  }}
/>
```

## 注意点
- カメラのパーミッションが必要
- ブラウザの互換性に注意
- パフォーマンスの最適化が必要
